Cómo trabajan tus Agentes y Programas con esta Bóveda

1. Tu rutina de la mañana en cualquier PC

malik login --server 
# ¿No quieres hacer login cada mañana en tu PC fijo?
malik login --server  --days 30

Guarda la sesión cifrada con Windows DPAPI en tu PC. Claude, Antigravity y tu terminal la usan automáticamente sin pedirte tokens.

2. Inyectar secretos en cualquier programa sin archivos .env

malik run -s apis/openai -s db/prod -- python app.py

Inyecta todas las claves en la memoria RAM del proceso hijo y censura cualquier fuga accidental en consola.

3. Compatibilidad directa con AWS Boto3

import boto3
sm = boto3.client(
    "secretsmanager",
    endpoint_url="",
    aws_access_key_id="mlk_live_...",
    aws_secret_access_key="unused",
    region_name="local"
)
print(sm.get_secret_value(SecretId="apis/openai")["SecretString"])
